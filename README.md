# 🛍️ AI Shopping Buddy — Smart Price Finder

> An AI-powered shopping assistant built with **Amazon PartyRock (AWS Generative AI)** for an internal AWS GenAI Hackathon conducted at our college.

## 📌 Project Overview

**AI Shopping Buddy — Smart Price Finder** is a generative AI-based shopping assistant designed to help users make smarter purchasing decisions.

Instead of manually checking multiple stores, comparing prices, searching for offers, and evaluating sellers, the app provides a single conversational interface where users can enter a product name and receive useful shopping insights.

The project was created using **Amazon PartyRock**, making it possible to build and demonstrate the AI application without developing a traditional software backend.

🔗 **Project Submission:** [AI Shopping Buddy — Smart Price Finder on Devpost](https://devpost.com/software/ai-shopping-buddy-smart-price-finder)

## ✨ Key Features

### 🔎 Smart Product Price Finder

Enter a product name, such as:

* Sony WH-1000XM4 headphones
* OnePlus Buds Pro
* KitchenAid Stand Mixer

The app analyzes the product and provides estimated pricing information.

### 🏪 Store Comparison

The application compares estimated prices and shopping information across multiple retailers, such as:

* Amazon
* Flipkart
* Croma
* Reliance Digital
* Vijay Sales

It can present information including:

* Estimated price ranges
* Bank and card offers
* EMI availability
* Shipping information
* Warranty details
* Return policies
* Store-pickup options

### 📊 Shopping Insights

The AI provides a **deal score** and summarizes whether a product appears to offer good value.

It can also provide:

* Expected price ranges
* Value-for-money analysis
* Competitive pricing insights
* Price-trend observations
* Potential sale periods
* Common bundle opportunities

### 💬 AI Shopping Assistant

Users can ask follow-up questions about:

* Product prices
* Product features
* The best time to buy
* Deals and discounts
* General shopping decisions

This makes the application more conversational than a simple price-comparison tool.

### ✅ Seller and Product Verification Guidance

The application provides guidance for evaluating whether an online seller or marketplace is trustworthy.

It can suggest checking:

* Business registration
* Secure payment options
* Customer service
* Authorized sellers
* Warranty coverage
* Purchase documentation

It also highlights safer shopping practices, such as avoiding suspicious payment methods and being cautious of deals that appear too good to be true.

## 🧠 How It Works

The application follows a simple generative AI workflow:

```text
       User enters product name
                 |
                 v
          AI analyzes product
                 |
        +--------+--------+
        |        |        |
        v        v        v
      Price    Store    Shopping
      Info   Comparison Insights
        |        |        |
        +--------+--------+
                 |
                 v
      Seller Verification Guidance
                 |
                 v
       Conversational Assistance
                 |
                 v
      Smarter Shopping Decisions
```

The application is built using **Amazon PartyRock**, with AI-powered components and prompts supporting different shopping tasks.

## 🎯 Hackathon Context

This project was developed as part of an **internal AWS Generative AI Hackathon at our college**.

Our goal was to explore how generative AI can solve a practical, everyday problem. We chose online shopping because consumers often need to compare prices, offers, seller reliability, and the right time to purchase across different platforms.

Using Amazon PartyRock, we developed an AI-powered shopping assistant that brings these shopping insights together in one place.

The project demonstrates how generative AI can be used to prototype an application that helps users make more informed purchasing decisions.

## ⚠️ Disclaimer

The prices and offers shown by the application are **AI-generated estimates** and may not reflect real-time prices.

Actual prices, discounts, availability, shipping charges, warranty terms, and return policies may vary depending on:

* Retailer
* Product model or variant
* Location
* Time of purchase
* Promotional events
* Payment method

Always verify the final price, product details, and seller information on the retailer's official website before making a purchase.
